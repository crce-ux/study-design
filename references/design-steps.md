# D1–D6 逐步详情

## D1 · 子假设落地

**目标**：把「研究假设」拆成**可操作、可证伪**的子假设。

### 每个子假设必须落地四项

| 项 | 要写清什么 | 反例（不合格） |
|---|---|---|
| **变量** | 自变量 / 因变量 / 协变量，各自类型（连续/分类） | 「分析 EEG 与疗效的关系」——哪个频段？哪个疗效指标？ |
| **测量** | 用什么工具、什么参数、谁评 | 「用 PANSS」——总分还是分量表？谁评？盲否？ |
| **时点** | 基线 / 治疗中 / 终点，各测什么 | 「治疗后测」——4 周还是 8 周？ |
| **证伪条件** | **什么结果算假设不成立** | 缺此项 = 不可证伪 = 不是科学假设 |

### 主假设与探索性假设要分层

二者统计待遇不同：

- **主假设** → 需多重比较校正、需样本量支持
- **探索性假设** → 明确标注「探索性」，不做校正但**结论不可当定论**

### 终点定义（**D1 的延伸**，不是新的一步）

「要测量什么」**不等于**「终点定义」。一个终点要说全**七件事**：

```
① 事件定义        什么算「发生」？
② 评估时点/随访窗  什么时候看？允许 ± 几天？
③ 时间原点        从哪一刻起算？
④ 复合逻辑        若复合：各部分怎么组合？重要性一致吗？
⑤ 裁定           谁判？争议怎么办？盲否？
⑥ 删失/截尾规则   什么情况下不计入？
⑦ 可捕获性        落到哪个字段/检查/量表？拿得到吗？
```

> 🔴 **只写①的，就是「给了阈值没给操作」**——在方案评审里只写①的终点定义就是半成品。
>
> ⚠️ **随访事件 ≠ 入排规则**：用结局筛人 = 用「之后才知道」的信息筛人
> （见 `confounders-and-bias.md` 的不死时间偏倚）。

完整判据（七个不许混、复合终点三个坑、替代终点边界）见 [`endpoints.md`](endpoints.md)。

## D2 · 样本量估算

### 估算四要素

| 要素 | 说明 | 常取值 |
|---|---|---|
| **效应量** | 来自证据表，**但须降级** | 乐观 = 文献值 × 0.7；保守 = × 0.5（经验值，须说明） |
| **检验效能** | 1 − β | 通常 0.80 |
| **显著性水平** | α | 0.05（双侧） |
| **脱落率** | 按同类研究估计 | （例：精神科队列 15–30%） |

### ⚠️ 先定比较策略，再定样本量

多重比较校正方式（Bonferroni / FDR / 层级门控）取决于**比较次数**。
**顺序反了会返工**——样本量算完才发现校正后效能不足。

### 交付格式

```
主分析样本量：N = ___（效能 0.80，α=0.05，效应量 d=___）
保守情形：    N = ___（效应量 d=___）
+ 脱落率 ___% → 需招募 N = ___
+ 与现有队列规模的对比（接 D4）
```

**不要只给单点值。** 给区间 + 假设来源 + 脱落率。

## D3 · 入排标准与分组定义

### 纳入 / 排除

| 维度 | 要点 |
|---|---|
| **诊断** | 诊断系统（DSM-5 / ICD-11）+ 评估工具（SCID） |
| **年龄 / 病程** | 与文献可比性（影响 D2 的效应量外推） |
| **排除** | 共病（物质依赖、器质性脑病）、妊娠、禁忌证 |
| **用药** | 是否限制合并用药、是否要求洗脱期 |

### 分组定义：阈值必须写明出处

**任何「切一刀」的分组，都要写出：标准来源 + 阈值。**

例（精神医学）：

- TRS 定义 → 依据 **Kane 标准** / **TRRIP 共识** / 中国专家共识
- 应答定义 → 阈值来源：PANSS 减分率 ≥50%，或 BPRS 改善 ≥20%

**不要**只写「难治性患者」「应答者」而不给判据。换成你自己的领域，同一条照做。

### 与文献分组的一致性检查

若本课题要与某篇文献比照，**入排与分组定义须先对齐**——
否则「我们的结果和他们不一致」可能只是定义不同，不是真矛盾。

## D4 · 可行性

| 维度 | 要落实什么 |
|---|---|
| **病例量** | 年门诊量 × 符合入排比例 = 可招募数（**须与 D2 需求数对比**） |
| **机时** | 设备数 × 每例耗时 × 随访次数；与临床排班冲突否 |
| **时间窗** | 与主队列 / 主 RCT 的衔接时点（**错过窗口 = 收不到数据**） |
| **人力** | 评估者、技师、盲法维持 |
| **资金** | 耗材、检查费、劳务 |

### 风险与应对

每项风险写四件事：**风险 → 概率 → 影响 → 应对**。

> ⭐ **可行性最常见的否决点**：**可招募数 < 样本量需求**。
> 必须做**数字对比**，不能只写"预计可满足"。

### 最小可行研究（**约束下砍到能跑的版本**）

约束不足时，产出应是「**当前条件下能跑、且仍有解释力的版本**」。

```
① 这个研究真正要回答什么？     —— 砍掉所有漂亮的附加项
② 资源分三堆：拿得到 / 可能拿到 / 拿不到
③ 主导约束是哪一个？           —— 不是所有约束等重
④ 最小可执行版本是什么？        —— 一路砍到它变得「真能建起来」
⑤ 哪些推迟 / 砍掉 / 标为依赖假设？
```

> 🔴 **不许编造资源。** 「应该能拿到」不算拿到。
> 拿不到就写拿不到，并在方案里标成**依赖假设**——不许把过建的计划伪装成可执行。

## D5 · 伦理与数据管理

### 伦理审查
- 伦理委员会名称、批件号（申请中须标注）
- 知情同意形式（书面 / 口头 + 见证）
- 弱势群体保护（若有）

### 数据管理计划
- 存储位置与权限（谁能访问）
- 脱敏规则（ID 映射表存放处）
- 保存年限（通常 ≥5 年）
- 共享范围（是否公开、何时公开）

### 预注册与透明度
- 注册平台与注册号（ChiCTR / ClinicalTrials.gov）
- **注册时点应早于首例入组**——事后注册会削弱可信度
- 与统计分析方案的一致性（偏离须报告）

## D6 · 混杂与偏倚复核

**D6 混杂与偏倚复核是「回过头查」的动作**，不是新写一节。拿 D1–D5 的成品来压测，结论**回写**进 D1（变量）、D2（协变量）、D3（分组）。

一句话：**「该不该校正」看的是变量角色。**

### 变量角色分类（**先分类，再决定**）

| 角色 | 控不控 |
|---|---|
| **混杂**（暴露与结局的共同原因） | ✅ 控 |
| **中介**（暴露 → 中介 → 结局） | ❌ 不控——校了把效应校没 |
| **对撞**（暴露与结局的共同结果） | ❌ 不控——校了**凭空造出关联** |
| **效应修饰**（改变效应大小） | ⚠️ 分层报告，不合并 |
| 噪声 | ❌ 不控 |

> 🔴 **判据是变量在因果图上站在哪。**

### 压测四问

1. 过度校正？ 2. 对撞偏倚？ 3. 选择偏倚？ 4. 时间顺序错了？

### 产出：最小可辩护控制集

控到**能辩护为止**，其余写明**为什么不控**。

完整判据（六个不许混、九步、六类偏倚、输出模板）见 [`confounders-and-bias.md`](confounders-and-bias.md)。
