# 十一条已知坑（复用前必看）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **D2 效应量照搬文献的「患者 vs 对照」值** | 患者组间比较效应量更小；给**乐观 / 保守两套** |
| 2 | **分组阈值来源不明** | 写明**本领域**依据（例：Kane / TRRIP / 中国专家共识），可被追问 |
| 3 | **样本量只给单点值** | 给区间 + 假设来源 + 脱落率 |
| 4 | **先算样本量后定比较策略** | 先定多重比较策略，再算样本量 |
| 5 | **可招募数未与需求数对比** | D4 必须做数字对比，不能只写「预计可满足」 |
| 6 | **伦理 / 数据管理后补** | 与主 RCT 衔接时最容易卡；D5 与 D1–D4 **并行**推进 |
| 7 | **预注册晚于入组** | 注册应早于首例入组 |
| 8 | **设计书依据追不到证据表** | 逐条审计：每条依据 → 证据表条目 |
| 9 | **入排定义与所引文献不一致** | 先对齐定义，再谈结果是否矛盾 |
| 10 | **假设无证伪条件** | D1 四项必须齐全，尤其「证伪条件」 |
| 11 | **裁决给结论而不给理由** | 说「不行」要有具体先例或反证；**感觉不算** |
| 12 | **终点只写了阈值**——没给裁定、评估窗、时间原点、删失规则 | 七件事写全（见 `endpoints.md`） |
| 13 | **校正了中介或对撞** | 先分变量角色；中介不控（会校没效应）、对撞不控（会造假关联） |
| 14 | **「把能拿到的变量都校正」** | 过度校正会引入新偏倚。控到**能辩护**为止 |
| 15 | **把软件默认值当成自己的选择** | 被问「为什么用这个」要答得出；默认值与主动选择分开标 |
| 16 | **可行性只写「预计可满足」** | 两个数字摆出来 + 砍到**最小可行版本** |
| 17 | **不写残余偏倚** | 说不清的就说「说不清」——隐瞒比承认更危险 |

---

## 每条坑的根因

前十条可以归成三类：

| 根因 | 涉及 |
|---|---|
| **没做数字对比** | 3、5、16 |
| **没写来源** | 1、2、9、15 |
| **顺序反了** | 4、6、7 |
| **没分角色 / 没写操作** | 12、13、14、17 |

**第 11 条单独一类**：它是**沟通纪律**问题——裁决的措辞会被反复引用，
把「我觉得」写成「证据不支持」，会在下一次被当成结论使用。

## 自检时的问法

写完方案，逐条问：

1. 「分组阈值我能不能立刻说出出处？」（不能 → 坑 2）
2. 「样本量的效应量从哪来？是患者组间的吗？」（不是 → 坑 1）
3. 「可招募数，我算过吗？」（没算 → 坑 5）
4. 「我如果拿到相反的结果，会怎么解释？」（能解释通 → 坑 10）
5. 「每条依据，我能指到证据表的哪一行？」（指不到 → 坑 8）
6. 「我这个终点，事件怎么定、谁判、什么时候判、不一致怎么办？」（答不全 → 坑 12）
7. 「我要校正的每个变量，在因果图上站哪——混杂、中介，还是对撞？」（分不清 → 坑 13/14）
8. 「我用这个阈值，是我选的，还是软件默认的？」（分不清 → 坑 15）
