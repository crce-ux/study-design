# 正反样例

五节，每节坏 vs 好。**左边过不了 `check_design.py`，右边能过。**

---

## 一、假设节 · 证伪条件

### ❌ 不好

```
假设：屏状核功能连接与氯氮平疗效相关。
```

导师追问「什么结果算不支持？」——答不上来。这句话**永远对**，
因为它没说在什么情况下它是错的。

### ✅ 好

```
主假设 H1：基线屏状核—前额叶功能连接强度与 12 周氯氮平疗效正相关。

证伪条件：若 ΔPANSS 与连接强度的偏相关系数 95%CI 跨 0（含 0），
则 H1 不成立。样本量按 r=0.30 估（见 D2）。
```

**差在**：写清了**什么结果算不支持**。

---

## 二、样本量节 · 乐观 / 保守两套

### ❌ 不好

```
样本量：估算需 120 例。
```

**只有单点值，没有来源、没有脱落率**——导师问「效应量哪来的」就卡住了。

### ✅ 好

```
D2 · 样本量（比较策略：先定校正方式，再定样本量）

主分析样本量：
  乐观  N = 100（效应量 r=0.35，来自 Zhang 2026 应答者—非应答者对比）
  保守  N = 160（效应量 r=0.27，按 D2 效应量降级规则下调一档——
        文献 r 多来自「患者 vs 健康对照」，本课题比的是患者组之间）

脱落率：精神科队列同类研究 15–30%（本中心既往 TRS 队列 22%）
→ 需招募：
  乐观 100 ÷ (1−0.15) = 118
  保守 160 ÷ (1−0.30) = 229
多重比较：3 个次级终点，用 Holm 校正
```

**差在**：两套都给、假设来源写明、**效应量为什么降级写出来了**。

---

## 三、可行性节 · 两个数字

### ❌ 不好

```
预计病例来源可满足研究需求。
```

`check_design.py` 的 G5 是软提示，但这一项单独就能否掉可行性——
「预计可满足」不是数字。

### ✅ 好

```
D4 · 可行性数字对比

| 项 | 数字 | 来源 |
|---|---|---|
| 年门诊 TRS 患者 | 600 | 本院 2025 年病案统计 |
| 符合入排比例 | 35% | 回顾 2025-01～06 病历 210 份，筛出 74 份 |
| 招募期 | 1.5 年 | 项目周期扣除伦理与启动 |
| **可招募数** | **315** | 600 × 35% × 1.5 |
| **需招募数（最保守）** | **229** | 见 D2 |

→ 315 ≥ 229，余量 86。**若脱落率升到 40%，需招募 267，仍够。**

最小可行版本（若招募不足）：砍次级终点至 1 个，主分析样本量降至 100，
需招募 143 ——**先砍什么、推迟什么，在这里定，不在中期定。**
```

**差在**：两个数字都摆出来、来源可追、**连「不够时砍什么」都先定好**。

## 四、混杂控制表 · 变量角色分类

### ❌ 不好

```
协变量：年龄、性别、病程、基线 PANSS、发病年龄、用药剂量、代谢指标、
       炎症因子、教育年限、家族史。
```

十个变量**全控**——其中至少两个是中介或对撞，控了就出事。

### ✅ 好

```
5.6 混杂因素控制总表

| 变量 | 角色 | 是否入模型 | 依据 / 理由 |
|---|---|---|---|
| 年龄 | 混杂 | ✅ 控 | 与连接强度和疗效均相关 |
| 性别 | 混杂 | ✅ 控 | 同上 |
| 基线 PANSS | 混杂 | ✅ 控 | 影响 ΔPANSS 的天花板效应 |
| 病程 | 混杂 | ✅ 控 | |
| **炎症因子** | **中介** | ❌ **不控** | 假说中炎症是连接→疗效的**通路**；控了会把效应控没 |
| **用药剂量** | **对撞** | ❌ **不控** | 剂量受疗效反馈影响（有效→维持，无效→加量）；控了会凭空造出关联 |
| 发病年龄 | 效应修饰 | 分层报告 | 预设亚组，不做全样本校正 |
| 教育年限 | 与本研究无关 | ❌ 不控 | 无理论路径 |

残余偏倚：未测的童年逆境可能同时影响连接与疗效，本设计无数据，**不隐瞒。**
```

**差在**：**先定角色再定控不控**；中介与对撞明确排除；
效应修饰改成分层报告；**残余偏倚写出来而不是装作没有**。

## 五、终点定义操作化

### ❌ 不好

```
主要终点：治疗有效。
```

什么算「有效」？谁判？什么时候判？丢了怎么办？——四个问题答不上来。

### ✅ 好

```
主要终点：12 周时 PANSS 总分较基线的变化（连续变量）。

| 项 | 定义 |
|---|---|
| 事件 | PANSS 总分变化值（基线 − 12 周），不做二分 |
| 时点窗口 | 12 周 ± 7 天；窗口外按最近一次观测，标为偏离 |
| 时间原点 | 首次服药日（不是入组日） |
| 裁定 | 无需裁定（连续变量，无主观判读） |
| 删失 | 未满 12 周即退出者：MMRM 用可得观测；**不做末次观测结转** |
| 可捕获 | CRF-03 量表页，评定者需通过一致性评定 |

次级终点含「应答率（≥30% 下降）」——**该二分终点的阈值 30% 来自
Leucht 2005 的荟萃分析，不是软件默认值。**
```

**差在**：七件事齐；**阈值写出了出处**，且明说它不是软件默认值。
