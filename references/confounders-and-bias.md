# D6 · 混杂与偏倚复核

> **D6 混杂与偏倚复核是一次「回过头查」的动作**——放在 D1–D5 之后，因为它是拿已写好的方案来压测。
> 但它的结论要**回写**进 D1（变量）、D2（协变量）、D3（分组）。

---

## 一句话

**「该不该校正」看的是变量角色。**

先把每个变量**归类**，再决定控不控。跳过分类直接问「该校正哪些」，必然得到「能拿到的都校正」。

---

## 🔴 六个不许混

| 不许混 | 为什么 |
|---|---|
| 混杂控制 ≠ 把所有能拿到的变量都校正 | 多控 = 过度校正，**会引入新的偏倚** |
| 预测变量 ≠ 混杂 | 预测力强 ≠ 该控。预测模型和因果推断要的东西不一样 |
| **暴露后变量 ≠ 基线协变量** | 时间顺序错了 |
| **中介 ≠ 校正对象** | 校正中介 = **把你要找的效应校没了** |
| **对撞 ≠ 有用的平衡变量** | 校正对撞 = **凭空造出一条关联** |
| 统计复杂度 ≠ 有效的因果控制 | 方法花哨不等于控对了 |

---

## 一、变量角色分类（**先分类，再决定**）

| 角色 | 是什么 | 控不控 |
|---|---|---|
| **混杂** | 暴露与结局的**共同原因** | ✅ **控** |
| 暴露 | 你研究的原因 | — |
| 结局 | 你研究的结果 | — |
| **中介** | 暴露 → 中介 → 结局 | ❌ **不控**（控了就把效应校没了） |
| **对撞** | 暴露与结局的**共同结果** | ❌ **不控**（控了会造出假关联） |
| **效应修饰** | 改变效应**大小**，不是偏倚来源 | ⚠️ **分层报告，不合并** |
| 噪声 | 与两者都无关 | ❌ 不控 |

> **判据是变量在因果图上站在哪。**
> 一个临床上极重要的变量，如果是对撞，校正它就是错的。

---

## 二、控制策略选哪个

| 策略 | 什么时候用 |
|---|---|
| 限制（restriction） | 混杂少而明确，可从入排直接排掉 |
| 匹配 | 病例-对照；混杂少、要平衡 |
| 分层 | 混杂是分类变量、层数不多 |
| 多变量校正 | 混杂多、样本够 |
| 加权 / 倾向评分 | 混杂多、事件数有限、想平衡整组 |
| 标准化 | 要报人群可比率（如年龄标化） |
| **阴性对照** | 要证明「不是残留混杂造成的」 |
| **敏感性分析** | 任何方案都该有 |

判据三条：**设计的类型 + 数据的可得性 + 混杂的测量质量**（测得准不准）。

---

## 三、九步

```
1  把目标估计量说清楚——问的是什么效应？谁对谁？
2  变量角色分类（上表七个）
3  找可能的混杂，以及**竞争通路**（另一条能解释结果的路径）
4  定哪些该控、哪些不该控
5  选控制策略
6  找偏倚（**要写推理，不是列名词**）
7  压测四问（见下）
8  说明**无法消除的残余偏倚**
9  给**最小可辩护控制集** + 稳健性检查
```

### 压测四问

1. **过度校正？** 有没有把中介/对撞放进模型？
2. **对撞偏倚？** 有没有校正了暴露与结局的共同结果？
3. **选择偏倚？** 入组或随访缺失，与结局相关吗？
4. **时间顺序错了？** 有没有用到「之后才知道」的信息？

---

## 四、六类点名要查的偏倚

| 偏倚 | 长什么样 |
|---|---|
| **过度校正** | 校正了中介或对撞 |
| **对撞偏倚** | 校正了暴露与结局的共同结果 |
| **不死时间偏倚** | 入组条件用到了「之后才知道」的信息（例：要求「存活 ≥30 天」才入组）——**队列 / 回顾性研究高发** |
| **错分** | 暴露或结局的测量本身就错（且与另一变量相关时更危险） |
| **选择偏倚** | 入组 / 随访缺失与结局相关 |
| **回忆偏倚** | 病例-对照，病例与对照的暴露回忆系统不同 |

---

## 五、不许做

- 不建议**不分青红皂白校正所有变量**
- 不把**预测性能**当成混杂控制有效的证据
- 不假设**用户没建立的时间顺序**
- 不把暴露后 / 结局后的变量当**基线协变量**
- 不暗示观察性校正能推出**因果**
- 🔴 **不隐瞒残余偏倚**——说不清的要说「说不清」

---

## 六、输出：最小可辩护控制集

标准是**控到能辩护为止，其余写明为什么不控**。

```
目标估计量：______
变量角色：混杂 ___ / 中介 ___ / 对撞 ___ / 效应修饰 ___ / 噪声 ___
最小可辩护控制集：{ ... }
为什么这些不控：中介 ___（会校没效应）· 对撞 ___（会造假关联）· ...
控制策略：______
残余偏倚（无法消除）：______
稳健性检查：______（如 E-value / 阴性对照 / 敏感性分析）
```
