# scripts/

**这里是运行版。正本在 [`research-workflow`](https://github.com/crce-ux/research-workflow) 的 `scripts/checks/`**——开发与测试都在那边。

改脚本请改总仓，再同步过来；**不要只改这里**（改了不会回流，两边会岔开）。

| 脚本 | 干什么 | 服务于 |
|---|---|---|
| `check_design.py` | 设计书结构机检：**G1** 证伪条件 / **G2** 乐观·保守两套 / **G3** 脱落率 / **G4** 风险四列 / **G6** 伦理与预注册 / **G7** 疗效阈值有没有写出处（**G5** 可行性数字对比为软提示） | 四条铁律 · D1–D6 |
| `sample_flow.py` | **样本量 → 需招募 → 可招募**：按脱落率给三套，按分组比拆每组，与最保守需求对比。**只做拿到主分析样本量之后的换算** | D2 · D4 |
| `check_skill_structure.py` | 结构校验（官方 Agent Skills 规范）：name / description / 正文长度 / 深链 / **声明落地** |
| `selfcheck.py` | **一条命令自检**：结构 + 语法 + 依赖。见下 |

## ⚠️ 它会标出你自己那份终稿

2026-10-14 实测 `TRS_EEG/03_课题申报/02_研究设计书_终稿_20260812.md`，**5 处**不符：

| | 缺什么 |
|---|---|
| G1 | 2.4 假设节 5/5 条没有证伪条件 |
| G2 | 3.2 样本量节没有「乐观 / 保守」两套效应量 |
| G3 | 3.2 没有脱落率 |
| G4 | 8.2 风险表只有「风险 / 概率 / 应对」三列，缺「影响」 |
| **G7** | 5.2 终点定义给了「PANSS 减分率 ≥30% 为有效」，但**没写出处** |

**这不是误报**——判据很清楚，是稿子没过自己写的线。改稿还是改铁律，由你定。

### G7 的触发面**故意很窄**

只认**疗效判定型的百分比阈值**（减分率 / 应答 / 缓解）。**不认操作阈值**——
像\"有效试次比例 ≥85%\"那种质控阈值本就不需要文献出处，放宽会把它们全报成缺出处。

文档**自己标了「待确认」**的，不再重复报（实测：初稿的待确认清单里列了这条阈值，被重复报过一次）。

## 会报「本次未评」

设计书**缺某一节**时（例如写着玩儿的「设想稿」没有假设节和样本量节），相关规则会整条跳过。
**跳过会打印出来**——否则屏幕显示「全过」，读者会以为是查过且通过了。那不是一回事。

## 边界

**脚本只做能自动化的那一半。**

它查**该有的东西在不在**，不查出处的标准**对不对**、效应量取得**合不合理**——一律语义。

> ⚠️ 但「**有没有写**出处」是**结构**，在查（G7）。这两件事别混——
> 此前 docstring 把「阈值出处」整条归为「语义，不查」，结果是
> **四条铁律里只有第 3 条没有任何机检**。

```bash
python scripts/check_design.py <设计书.md>
python scripts/check_design.py <设计书.md> --deliverables <03_课题申报/>   # 另查交付物清单（只报不判）
```

## 自检

```bash
python scripts/selfcheck.py            # 结构 + 语法 + 依赖
python scripts/selfcheck.py --strict   # 结构警告也算失败（CI 用这个）
```

查三样：**结构**（官方规范）· **语法**（逐个编译 `scripts/*.py`）· **依赖**（哪些脚本要装第三方库，只报不判）。
下载本 skill 后想确认「东西是齐的、没坏的」，跑这一条就够。
